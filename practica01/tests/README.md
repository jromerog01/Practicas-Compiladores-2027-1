# Pruebas — Práctica 1

Este directorio contiene dos conjuntos de pruebas, cada uno con la misma convención
`inputs/*.mc` + `expected/*.out`:

- **`public/`**: pruebas mínimas proporcionadas con la práctica. Ver `public/README.md`.
- **`propias/`**: pruebas escritas por el equipo, independientes de las públicas. Ver
  `propias/README.md`.

`make test` ejecuta ambos conjuntos y reporta `PASS`/`FAIL` por cada caso.
