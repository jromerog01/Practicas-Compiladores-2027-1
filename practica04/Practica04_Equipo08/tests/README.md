# Pruebas — Práctica 3

- **`public/`**: pruebas públicas de la Práctica 3. Ver `public/README.md`.
- **`propias/`**: pruebas del parser escritas por el equipo. Ver `propias/README.md`.
- **`lexer/`**: pruebas de las Prácticas 1 y 2, conservadas sin cambios. Comparan
  la secuencia de tokens impresa, por lo que ya no se ejecutan con `minic`, que
  en la Práctica 3 no imprime tokens.

`make test` ejecuta las pruebas públicas y las propias.
